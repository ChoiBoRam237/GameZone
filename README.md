### 개발환경 : Windows

### 기능 소개
#### 1. 랜덤 룰렛
- 원하는 아이템을 자유롭게 추가할 수 있습니다.
- 아이템을 수정하거나 삭제할 수 있습니다.
- 룰렛 결과를 팝업으로 확인합니다.

#### 2. 랜덤 카드 뽑기
- 원하는 아이템을 자유롭게 추가할 수 있습니다.
- 아이템을 수정하거나 삭제할 수 있습니다.
- [카드 섞기] 버튼을 눌러 카드를 무작위로 섞어 배치합니다.
- 원하는 카드 하나를 선택하면 카드가 열리며 결과를 확인할 수 있습니다.

#### 3. 동전 던지기
- Start 버튼을 누르면 동전이 회전하며 앞·뒤 중 하나가 결정됩니다.
- 동전 던지기 결과를 팝업으로 확인할 수 있습니다.
